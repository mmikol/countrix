# The screenshots

The guide's pictures: the real board on the built database, the shipped
playbook in force (no `COUNTRIX_STRATEGIES`), in Chrome at a window
1440 px wide, PNG. They show the numbers the board computes: the owner
opened the guide's screenshots to them on 2026-10-05 (CLAUDE.md, the
user guide); the pages' text quotes none. Each board picture is taken
once the board's reply has landed and been drawn, so every slot holds a
hero and nothing reads *solving*. A picture that would pass 400 KB is
stored in 256 colours or fewer. The README's three pictures, in
`docs/img/`, are taken the same way on the README's draft, JPEG at
quality 85: the board's top, then blue's six and its bars at twice the
pixels. The pages show each under the alt text they give it. This file
is no page: the build leaves it out (`exclude_docs` in `mkdocs.yml`).
