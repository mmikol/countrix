# Security

Countrix runs on your own machine, against public sources and your own
Claude Code subscription, at your own risk.

The software comes as is, without warranty, as the licence states, and
its owner offers no support. Whoever runs it is responsible for their own
deployment: the machine, the network it listens on, the sources it pulls
from and the accounts it uses.

[docs/security.md](docs/security.md) describes what the code does, with no
assurance that it is enough for you.

Report a vulnerability privately, as a GitHub private vulnerability
report from the repository's
[Security tab](https://github.com/mmikol/countrix/security) or as a
direct message.
